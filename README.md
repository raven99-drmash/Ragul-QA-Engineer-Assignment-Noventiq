The suite will validate UI functionalities of "https://practicetestautomation.com/practice-test-login/"

* User lands on login page
* Fields and page title are visible
* Valid and invalid login scenarios
* Error messages for negative tests

* Tech Stack
Playwright
TypeScript
Node.js

Running all tests:
Use below command
  npx playwright test

To view reports of older execution:
  test-results/report-YYYY-MM-DD_HH-MM-SS/index.html
  
Test cases Excel file: /test-data/TestCasesDoc.xlsx
